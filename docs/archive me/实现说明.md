## 二、空间结构

- 白天庭院：铺地、草地、树、石栏、门前五级台阶与垂带石，`Z = +21` 起向城门走。
- 门楼：砖砌城墙（两侧各约 11.6m）+ 门墩 + 木门（门钉、门环）+ 匾额 + 灯笼 + 斗拱 + 重檐屋顶 + 石狮。
- 城楼（参照正阳门 / 西安城楼的三段式结构重建）：城台（砖砌城墙，顶设压顶石）之上是**台明 + 楼板**，楼板上立一圈檐柱（面阔五间 `bayW=2.08`、进深三间 `depth1=2.55`、柱高 `2.75`），柱间有寻杖栏杆；柱头用**额枋 + 平板枋**连成整体，其上起**腰檐**（四面围合的腰檐，四角起翘，檐下有望板与露明椽头）；腰檐之上再立上层柱、三间两段式格扇（上段透光纸 + 5 竖 3 横棂条，下段实心裙板），柱头再收一层额枋，挂「时之画廊」竖匾；最上是**歇山屋顶**：前后坡 + 两端山花三角封板 + 正脊、垂脊与吻兽，檐口同样做封檐板、望板与椽头。
- 城楼不再使用「一排比屋檐还宽的斗拱」——那种做法从街面看只是一排黑色梳齿；现在结构层次由柱网、额枋、腰檐、歇山四层关系交代，城台檐下保留斗拱。
- 大门两侧的石鼓换成**抱鼓石**：两层须弥座 + 立起的鼓身（鼓面圆凸）+ 卷草托。
- 门后是砖砌拱顶长廊：净宽 `4.6m`、起拱高 `3.0m`、拱顶高约 `4.0m`，沿 `-Z` 延伸；右墙开高窗采光，左墙挂画。
- **室内地面比庭院高 `0.9m`（`ROOM.floor`），与门槛齐平**，相机高度同步抬升，穿过门洞时没有落差。
- 右墙窗是真实洞口：墙体在窗宽处断开，窗外是整片远景背板 + 透光玻璃 + 木窗棂，窗台有溢光。窗外贴图压暗成天光 + 树线，避免逆光时变成一块白板。
- 门洞上沿补了一段 `entryHead` 墙体，把拱顶与门洞之间的空隙封住，从门外仰望不会再露出天空。
- 画作间距 `3.2m`，中心高 `1.62m`，金框 / 深木框交替，框内有卡纸与下方黄铜展签；画框上沿装罩式画灯（钟形灯罩 + 灯泡，每三幅一盏暖光点光源）。
- 拱肋每 `4.2m` 一道，托石落在墙上；中轴悬挂铜环玻璃球吊灯（灯口朝上、每盏带点光源）；左墙下长椅；地面深灰石地 + 暗红波斯地毯。
- 拱顶灰泥贴图带抹刀弧线、污渍、裂纹与 bump，近看有手工抹灰的质感。
- 尽头没有实体端墙：走廊继续向雾里延伸，形成「无尽走廊」。


## 三、画作即文章

- 每篇文章（系列则每个章节）生成一张 `900×1200` 海报：封面图、栏目名、章节号、标题、日期/字数/分类、摘要、READ THE ARTICLE。
- 有封面的文章会异步载入封面并重绘海报；没有封面时用同色系抽象底图。
- 因此“看画识文”靠的是海报版式与封面，而不是抽象画。

## 四、滚动即前进

- `.arc-scene` 高度 = `clamp(150 + 幅数 × 26, 220, 520)`（移动）/ 桌面稍长；舞台 `position: sticky` 固定。
- `progress = 已滚动距离 / (场景高 - 视口高)`，相机沿关键帧插值：街面 → 门前 → 穿门 → 长廊。
- 进度 `0.02 / 0.18` 之间双门绕铰链向内开；点门或「推开城门」直接滚到入廊位置。
- 滚动到尽头后舞台淡出，下方是文字版归档。

## 五、特写

- 画作是真实 3D 网格，鼠标悬停用射线拾取（`Raycaster`），命中时画框描边发亮、光标变 pointer（不再有正对镜头的 DOM 方框）。
- 点击后相机 lerp 到画前，右侧浮出展签卡片（竖屏为底部抽屉）。
- 卡片含标题、日期、字数、分类、系列章节、`阅读全文`、`上一幅 / 下一幅`、`返回画廊`。
- `←` / `→` 切换，`Esc` 退出。

## 六、主题与性能

- 页面固定为白天场景，强制使用暗色 UI 变量，避免浅色主题把文字压没。
- 桌面 2 倍像素比、移动 1.5；移动端关闭阴影与部分灯。
- 所有贴图在初始化时一次性生成，切换主题不再重绘。

## 七、已知取舍

- 屋顶是程序化重檐（瓦垄贴图 + 起翘曲面 + 脊兽），远看成立，近看仍是概括造型；瓦面为单层曲面加双面材质，没有做出瓦的厚度与瓦当滴水。
- 石狮为几何拼装（后胯、胸腔、直立前腿、鬃毛两圈、开口与獠牙），正面可辨，侧面仍偏概括。
- 拱顶灰泥靠贴图 + bump 表达，没有做真实置换。
- 截图里页面顶部偶尔出现黑带，是 Playwright 窗口截图的取样问题，不是页面布局。
