请你作为一名资深的 Three.js 与 WebGL 交互开发工程师，为我的 3D 博客归档画廊编写一个高度模块化、手感丝滑的相机控制与交互系统（建议封装为独立的 `GalleryCameraController` 类，动画可使用 GSAP 或自定义阻尼插值 `lerp`）。

### 场景空间前提
- 画廊沿 Z 轴向负方向延伸（假设大门在 `Z = 0`，画廊内部向 `Z < 0` 延伸）。
- **所有博客文章画作均单排挂在左侧墙面（`X = -wallOffset`）**，面向右侧（法线朝 `+X`）。
- 行人相机默认高度 `Y = 1.6`。

---

### 1. 状态机设计（State Machine）
请将相机交互严格划分为以下 5 个状态，避免不同操作间的事件冲突：
1. `OUTSIDE_GATE`：在大门外等待点击开门。
2. `ENTERING`：开门并推镜进入画廊的过场动画中（此时锁定用户输入）。
3. `BROWSING`：走廊自由浏览状态（核心状态）。
4. `INSPECTING`：单幅画作特写查看状态。
5. `TEXT_ARCHIVE`：滑过最后一幅画后，释放页面滚动权，进入网页下方的 2D 文字版归档。

---

### 2. 入场与左墙视角对齐（`OUTSIDE_GATE` -> `ENTERING` -> `BROWSING`）
- 大门开启后，相机平滑沿 Z 轴推进进入画廊。
- 在进入走廊的同时，相机视线（`lookAt` 目标点）**丝滑地向左微微偏转**（例如保持相机在走廊中线偏右一点，朝向左前方约 30°~45°），确保在常规浏览视角下，**画面中能同时清晰看到左侧墙面的 3~4 幅文章画作**，兼顾空间纵深感与画作可读性。

---

### 3. 走廊浏览交互（`BROWSING` 状态）
- **前进与后退**：
  - **PC 端**：鼠标滚轮向下滚动（`deltaY > 0`）控制相机沿走廊前进；向上滚动（`deltaY < 0`）控制后退。
  - **移动端**：手指在屏幕上**向右滑动**对应前进，**向左滑动**对应后退。
  - 所有位移均需带有**惯性阻尼（Smooth Damping）**，松手后有轻微滑行减速感。
- **鼠标视差（Mouse Parallax）**：
  - 在 PC 端浏览时，监听 `mousemove` 事件，将鼠标归一化坐标（`-1` 到 `1`）映射为相机旋转角度或 `lookAt` 目标点的微幅偏移（使用低系数 `lerp` 平滑跟随），增强沉浸感且不引起 3D 眩晕。
- **双端边界处理**：
  - **起点边界（允许退回大门外）**：当用户持续后退越过画廊入口阈值时，相机平滑退回大门外（切换回 `OUTSIDE_GATE` 状态，可触发关门动画或重新显示入口提示）。
  - **终点边界（无缝衔接文字版归档）**：当用户滑过最后一幅画并继续向下滚动时，触发状态切换至 `TEXT_ARCHIVE`。此时解除 3D Canvas 对滚轮事件的拦截（`preventDefault`），让网页自然向下滚动展示下方的 HTML 2D 文字版博客归档列表；当用户从文字版滚回页面顶部时，重新无缝接管回 `BROWSING` 状态。

---

### 4. 画作特写与 2D 虚拟旗帜 UI（`INSPECTING` 状态）
- **进入特写**：在 `BROWSING` 状态下，通过 `Raycaster` 检测到用户点击左侧墙面的某幅画作时，切换至 `INSPECTING` 状态，暂停鼠标视差与滚轮推进。相机平滑移动并正对该画作中心（视线垂直于左墙）。
- **2D 虚拟旗帜与控制按钮（HTML Overlay）**：
  - 特写到位后，将当前画作右侧边缘的 3D 世界坐标通过 `vector.project(camera)` 投影为 2D 屏幕坐标，在**画框右侧**弹出一个古风/中世纪风格的 **2D HTML 虚拟旗帜按钮“前往”**，点击后跳转至对应文章链接。
  - 在屏幕底部或合适位置提供 2D 控制栏：**“上一幅”**、**“下一幅”**、**“退出特写”**按钮。
- **快捷切换与键盘支持**：
  - 点击“上一幅 / 下一幅”或按下键盘 `ArrowLeft` / `ArrowRight` 时，相机直接沿左墙平滑横移至相邻画作的特写位置，同时更新右侧“前往”旗帜的链接与动画。
  - 点击“退出特写”或按下 `Escape` 键时，隐藏所有特写 UI，相机**平滑退回到当前所看画作对应的走廊浏览位置**（而非最初点击的那一幅），并恢复 `BROWSING` 状态。

---

### 5. 移动端竖屏适配（Responsive）
- 监听 `window.resize` 与屏幕宽高比（`aspect < 1` 判定为竖屏移动端）：
  - 在 `INSPECTING` 模式下，根据视口宽高比自动计算并**拉远相机与画作的距离**，确保完整展示画框。
  - 移动端竖屏下，将原本在画框右侧弹出的 2D“前往”虚拟旗帜，**自动改为在画框正下方弹出**，防止超出屏幕右边界。
