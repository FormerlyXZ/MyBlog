这是我学习 STM32F103（Keil MDK + 标准库）的完整笔记，从环境搭建一直记到 ADC。
整份笔记按「章」组织：一篇就是一章，左侧可以切换章节，右边是本章的目录。

> **对应课程**：<a href="https://www.bilibili.com/video/BV11X4y1j7si" target="_blank" rel="noopener noreferrer">铁头山羊 STM32 入门教程【新版】</a>
>
> 这份笔记就是跟着这套视频记的 —— 视频里讲的每个实验，对应章节里都能找到完整代码。

## 这份笔记怎么用

- **按顺序读**：从第一章的环境搭建开始，后面的实验都建立在前面的代码之上；
- **当工具书查**：每个外设的章节基本遵循「原理 → 寄存器/结构体 → 初始化 → 读写实验」的节奏，
  忘了哪个外设直接跳进去看对应那章；
- **代码都在正文里**：每处功能都有完整的 `c` 代码块，可以直接复制到自己工程里。

## 硬件与软件环境

| 项目 | 说明 |
| --- | --- |
| 开发板 | STM32F103C8T6 最小系统板（核心板） |
| 下载器 | ST-LINK V2 |
| 开发环境 | Keil MDK 5（需装 STM32F1 支持包 + ST-LINK 驱动） |
| 库 | STM32 标准外设库（StdPeriph Library） |
