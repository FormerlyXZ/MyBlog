欢迎来到我的博客 👋

这是第一篇文章，你可以直接把它删掉，或者改成自己的开场白。

## 这个博客是怎么搭的

它本质上是**一堆静态文件**：

1. 我用 Markdown 写文章（就是纯文本，带一点格式标记）
2. Astro 把 Markdown 编译成 HTML
3. 生成的文件丢到静态托管上，全球 CDN 直接分发

没有数据库，没有服务器，没有后台登录，也不怕流量突然变大。

## 怎么发一篇新文章

在 `src/content/posts/` 目录里新建一个 `.md` 文件，比如 `my-new-post.md`，开头写上这段"配置区"（叫 frontmatter）：

```yaml
---
title: 文章标题
description: 一句话摘要，会显示在列表里
date: 2026-10-20
tags: [标签1, 标签2]
draft: false
---
```

然后下面正常写正文就行。文件名会变成网址：`my-new-post.md` → `/posts/my-new-post/`。

> **几个约定**
>
> - `date` 一定要写，格式 `2026-10-20`
> - 想暂时不发布，把 `draft` 改成 `true`
> - 中文文件名也能用，但建议用英文小写加短横线，网址更好看

## 本地预览

改完想看效果，在项目目录运行：

```bash
npm run dev
```

浏览器打开 `http://localhost:4321` 就能看到。按 `Ctrl + C` 停止。

## 发布

提交到 GitHub 之后，托管平台会自动重新构建并上线，大概 1 分钟。细节见《[把这个博客部署上线](/posts/deploy-guide/)》这篇。
