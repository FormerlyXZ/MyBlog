这是后台编辑器的自检文章，用来确认「写文章 → 提交 → 自动部署」整条链路是通的。

## 验收要点

1. 用户在 `/admin/` 登录后能新建文章
2. 保存后 GitHub 上出现一次 commit
3. 大约 1 分钟后线上能打开这篇

一段代码块测试：

```js
const message = '后台保存成功';
console.log(message);
```
